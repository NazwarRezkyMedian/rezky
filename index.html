📚 Penjelasan

🌐 DNS Server
DNS Server adalah sistem yang mengubah nama domain menjadi alamat IP.
Gunanya: mempermudah pengguna mengakses website tanpa menghafal IP.


🖥 Web Server
Web Server adalah sistem yang menyimpan dan menampilkan website kepada pengguna.
Gunanya: menjalankan website agar dapat diakses melalui internet.


🔒 SSH Server
SSH Server adalah layanan untuk mengakses server secara aman dari jarak jauh.
Gunanya: mempermudah konfigurasi dan pengelolaan server.


📡 Mikrotik
Digunakan untuk mengatur jaringan, hotspot, firewall, dan bandwidth.


⚙ Cisco
Digunakan untuk membangun dan mengelola jaringan komputer.
